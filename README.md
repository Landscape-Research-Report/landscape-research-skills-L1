# landscape-research-skills-L1 · 风景园林科研与写作技能集

一个面向风景园林 / 景观生态 / 城乡规划 / 设计学 / 自然地理等方向研究生的技能集合，覆盖从「选题与研究设计」到「论文生成与润色」的全流程。三个技能全部离线内嵌，不依赖运行时联网。

## landscape-research-skills包含的技能

开源版目前提供以下三个skill，本链接下即可下载。

### landscape-research

风景园林论文写作与选题伴侣。回答研究思路梳理、科学问题与选题、创新点、文献检索与综述、期刊与学位论文框架写法、选刊投稿、盲审与学科范畴规避、导师与申博等问题，并提供 12 个研究方向（生态系统服务、生态网络、城市热岛、碳汇、生物多样性、街景、乡村遗产、韧性、健康城市、公平可达性、景观格局等）的研究内容、方法、创新点与差异化切入点的蒸馏文件。内置 8 篇研究生指南问答与 12 篇方向文献蒸馏报告（带真实统计）。

### landscape-thesis-writing

风景园林学位论文生成（thesis-generator）。根据事实、实验结果、笔记或数据描述，生成符合学位论文语感的段落。规则体系 R1–R46 全部来自对 42 篇学位论文（41 篇有效，约 3 万句语料、105 个「结果与分析」章节）的实测蒸馏统计，覆盖语料证据写作规则、反 AI 声规则，以及从原始结果生成的规则。

### landscape-thesis-polish

风景园林学位论文润色。对已有论文初稿文字按实测规则打磨为清晰、紧凑、可读性强的学术中文。与 writing 共用同一份 rules.md（R1–R46），并附带 check.py 机械检测器，可自动标出违规句式与词汇。

## landscape-research-max-skills（满血版）包含的技能

L1 技能集之外的进阶满血版技能，知识库更大、覆盖更全，同样离线可用、不依赖运行时联网。获取连接：<https://xhslink.com/m/6OAmDXJ9BGj>

### landscape-research-max

风景园林科研问答助手（全文件知识库·满血版）。在landscape-research的基础上新增内置了10余个「文献全方向汇总表.md」（文献笔记的全部文件，并非蒸馏版本）。它能够调用知识库真实文献，在输出回答时给出参考的文献信息，不编造文献或数据。大家有任何问题都可以直接提问。

### landscape-lit-review

输入研究题目或主题，通过检索内置的「文献全方向汇总表.md」，按学位论文或期刊论文的类型成稿，输出可直接使用的硕士和博士学位论文、期刊论文的文献综述。基于已有文献汇总表md文件，引用全部来自检索结果或用户明确提供的文献，不凭空生成。

## 安装

本技能集是纯文本（Markdown + 脚本），不绑定某一款 AI 工具，可移植到任意支持「自定义指令 / 系统提示 / 知识库」的 AI 环境。每个技能文件夹的结构一致：

```
<skill>/
├─ SKILL.md          # 指令与领域知识（即系统提示 / 自定义指令）
├─ references/       # 知识文件（文献蒸馏报告、框架模板等）
└─ scripts/          # 可选的 Python 辅助脚本
```

**WorkBuddy**

把技能文件夹复制到 WorkBuddy 的技能目录之一：

- 用户级（所有项目可用）：`~/.workbuddy/skills/`
- 项目级（团队共享）：`<项目>/.workbuddy/skills/`

```
cp -r landscape-research ~/.workbuddy/skills/
cp -r landscape-thesis-writing ~/.workbuddy/skills/
cp -r landscape-thesis-polish ~/.workbuddy/skills/
```

复制后重启 WorkBuddy，在对话里用 `@skill:landscape-research` 等形式调用。技能目录名必须与 SKILL.md 里的 `name:` 字段一致。

**其他 AI 工具**

SKILL.md 本质是一段结构化指令，多数工具都能直接复用：

- 自定义指令 / 系统提示类（如 ChatGPT 自定义 GPT、Claude 项目指令）：把 SKILL.md 内容粘进指令框，再把 `references/` 文件作为知识或附件上传，模型即按该技能的方式作答。
- 编辑器 / 本地 Agent（如 Cursor、VS Code Copilot 工作区、本地大模型前端）：把整个技能文件夹放进项目目录，在对话或规则文件里指向 SKILL.md，并提示模型优先读取 `references/` 资料。
- 带脚本能力的环境：`scripts/` 下的 Python 脚本可独立运行（如 `python scripts/gen.py --help`），不依赖特定平台。

具体调用写法与脚本参数见下文「使用方式」。

## 目录结构（以 landscape-research 为例）

```
landscape-research/
├─ SKILL.md                  # 元数据 + 路由 + 回答风格 + 反AI痕迹约束
└─ references/
   ├─ index.md              # 总路由表：问题类型 → 文件
   ├─ graduate/             # 8 篇科研全流程问答指南
   ├─ thesis/               # 12 个方向文献蒸馏报告
   └─ assets/               # 期刊/学位/开题框架模板
```

landscape-thesis-writing 与 landscape-thesis-polish 结构类似，含 `references/rules.md`（R1–R46）、`references/gen_guide.md`、`scripts/gen.py`、`scripts/check.py`。

## 使用方式

- 直接提及需求即可触发，例如：「帮我设计重庆滨江公园游憩空间的研究思路」「润色这段结果与分析」「根据这组数据生成论文段落」。
- landscape-thesis-writing 的脚本可独立运行：`python scripts/gen.py --help` 查看参数（支持 `--list`、`-c/--chapter`、`-f/--facts`、统计类 `--top-*` 等）。
- landscape-thesis-polish 的检测器：`python scripts/check.py <输入文件> --out <报告>`。

## 规则体系说明

三个技能共享一套「语料实测驱动」的理念：所有写作与润色规则都不是凭空设定，而是从真实学位论文语料中统计、归纳、验证得来。landscape-thesis-writing 与 polish 的规则编号为 R1–R46，其中 R13–R34 专门抑制生成式 AI 的常见声口（生硬句式、互联网黑话、模板化结构）；landscape-research 也内置了「反 AI 痕迹硬性约束」一节来约束回答文字。
