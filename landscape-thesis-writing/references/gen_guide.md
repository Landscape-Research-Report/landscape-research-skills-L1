# 风景园林学位论文「生成」指南（landscape-thesis-writing）

本技能的目标是：基于 42 篇风景园林学位论文蒸馏出的「分章节写作范式」，**直接生成能用的论文文字**——常用语、语句结构、整段草稿。它不是凭空编，而是从真实范式中检索结构、用你给的事实填充。

## 一、生成 ≠ 编造事实

- 你提供的「事实/要素」是骨架：研究对象、地点、问题、方法、发现、结论。技能只负责**包装成学科规范的文字**，绝不替你编造数据、结论、引用。
- 没有的事实就留占位符（如 `[待补：具体指标值]`），不要硬编数字。
- 术语保全：`domain_lexicon.md` 里的词与缩写必须原样保留（如「生态系统服务（ES）」「景观连通性」）。

## 二、把「槽位模板」变成通顺段落的四步

1. **取结构**：用 `scripts/gen.py -c "<章节>" -f '<facts>'` 取出该章节的句式模板库（每类含「抽象槽位 + 真实例句」）。
2. **填事实**：把你的要素映射到槽位里的 `[对象]/[特征]/[手段]/[目的]/[依据]` 等占位符。先产出 2–4 个「初稿骨架」句子。
3. **扩写连贯**：把骨架扩成段落——用「推荐句首词」换开头避免千篇一律；用「推荐领域术语」替换口语词；用连接词（因此、在此基础上、与此同时）串成线性推进（R3）。
4. **自检定稿**：按 `rules.md` 的 R1–R12 过一遍，重点 R1 短句（>45字优先拆）、R7 强动词（删「进行/加以/予以/开展/实现」、把「起到…作用」改具体动词）、R4 去空泛套话、R10 精确量化。

## 三、保留学位论文「必要范式」（不可为追简洁而删）

这些是风景园林学位论文的惯用框架，生成时必须保留，不要当冗余删掉：
- 摘要/绪论：「本文以 **X** 为研究对象，以 **Y** 理论为指导，运用 **Z** 方法，旨在…」
- 研究背景：「随着…（城市化/老龄化/生态文明），X 问题日益凸显」
- 研究意义：「对…具有理论意义与现实意义」
- 方法：「采用…（如层次分析法/AHP、空间句法、SD 法、GIS 叠加），从…维度构建评价指标体系」
- 结论：「本研究得出以下结论：1）… 2）… 3）…；并指出不足与展望」

## 四、分章节取向（生成强度）

| 章节 | 取向 | 注意 |
|---|---|---|
| 摘要（中文/英文） | 沙漏结构：背景1句→目的1句→方法1句→核心发现2–3句→结论1句 | 英文摘要套 Nature 英文规则：短句、主动、无 fluff、说清 did/found/why |
| 绪论/研究背景/意义 | 弱动词可接受（范式框架），但避免空泛 | 保留「本文以…为对象」 |
| 文献综述与理论基础 | 重「谁做了什么、得出什么、仍有空白」的线性综述 | 用「据此/然而/既有研究多聚焦…鲜有涉及…」显式衔接 |
| 研究区概况与数据来源 | 客观陈述：区位、尺度、数据及精度 | 精确量化（R10），不写「一些/较多」 |
| 研究方法 | 可复现：对象、步骤、参数、工具 | 被动可保留（方法描述惯例），但要具体 |
| 结果与分析 | 先摆事实再解释；图表对应文字精炼 | 强动词、精确数字、避免「存在一定的」 |
| 讨论 | 与文献对话：印证/补充/反驳 | 显式对比「与 X 的研究一致/不同」 |
| 结论与展望 | 收敛为 3–5 条；展望点到为止 | 不夸大，不新抛数据 |

## 五、常见翻车点

- **堆模板**：不要一段里塞 5 个「随着…的 X，…」。每类模板用 1 次足矣，其余用同义变体。
- **填空不像人话**：槽位填充后一定通读，生硬处改写（如「为城市公园提供理论支撑」可扩为「上述理论为城市公园的康养化更新提供了分析框架」）。
- **术语打架**：同一概念全文统一（如「生态系统服务」不要后文变「生态服务」）。
- **英文摘要中式英语**：用短句主动态，避免「This paper through… method carries out…」式堆叠。

## 六、与润色技能的关系

本技能生成初稿；若成稿仍需打磨，交给 `landscape-thesis-polish` 技能做 nature-polishing。两技能共用 `rules.md` 与 `domain_lexicon.md`，口径一致。

## 七、从原始实验结果 / 笔记 / 数据描述生成（新输入模态）

除「给要素 → 填模板」外，本技能也能接受**原始材料**——实验结果（统计量、p 值、显著性、图表结论）、田野/观测笔记（bullet 观察、现场记录）、数据描述（原始测量值、字段说明、表格），并转写为「结果与分析」段落。规则见 `rules.md` 第五节（R35–R45，基于 42 篇语料结果章节实测）。流程：

1. **判型（R35）**：判断输入是实验结果 / 笔记 / 数据描述，或混合；混合型先分段再各自成段。
2. **抽取事实**：从原始材料提取【对象 / 指标 / 数值 / 单位 / 显著性(p) / 对比组 / 趋势】，缺失标 `[待补：…]`，未给的统计量不补（R36）。
3. **取范式**：`python gen.py -c "结果与分析" -f '{}'` 取该章术语/句首词/模板；术语对照 `domain_lexicon.md` 保全（R44）。
4. **成段**：按 R37–R43 转写——保精度单位（R37）、图表提炼非罗列（R38）、显著性规范（R39）、客观态（R40）、相关≠因果（R41）、笔记升段（R42）、数据转叙述（R43）。
5. **守边界并补现实解释**：结果段 = 事实描述 + 一句"现实解释"（由本数据直接支撑的平实含义，见 R46）；机制阐释、文献对标、设计处方仍留"讨论"（R45）。
6. **自检**：过 R35–R45 + R1–R34（尤其 R2 衔接保留、R10 术语、R23 动词起句忌、R27 不夸大、R34 少分号）。
