# 风景园林学位论文写作规则（语料实测版 · R1–R12）

> **本规则集不是从 Nature 编辑准则移植来的。** 它基于对用户提供的 42 篇风景园林学位论文的全文蒸馏语料（`chapters.json`，有效 41 篇、242 个中文章节、30906 个句子）做的**实测统计**生成。每一条规则都附语料证据（出现频次 / 覆盖论文数），说明它针对的是"这批论文真实存在的写法习惯"，而非外部审美。
>
> Nature 的写作准则（短句、强主动、去衔接词）只在**与本语料实测一致**处作参照；凡与本语料实测冲突的，以本语料为准。关键冲突见文末「与 Nature 假设的分歧」。

## 二、规则细则（R1–R12）

### R1 句长：长句为本批常态，不普遍拆短
- **实证**：中位 60 字、22% 超 100 字、p90 = 152 字。
- **规则**：默认保留原文信息密度，**不要像 Nature 那样把每句压到 20–30 字**。仅当单句 **>150 字且含 ≥3 个分句 / 多层修饰、读者需回读**时才拆分。
- **正**：「城市公园作为绿色基础设施，其空间品质与健康效益的关系已被大量实证研究证实。」（60 字，保留）
- **反**：强行把上句拆成 5 个碎句、丢失因果链条。

### R2 显式衔接词保留（不删）
- **实证**：因此/然而/综上所述 1379 次、覆盖 36/41 篇——这是本学科的论证纹理。
- **规则**：润色时**保留**显式衔接词，不要为"简洁"删去。只在衔接词堆叠（一句俩"因此"）时合并。
- **正**：「A 与 B 呈正相关。因此，优化 B 可间接提升 A。」（保留因此）
- **反**：把"因此"删掉假装自然语言流畅——这会破坏论文的逻辑显性。

### R3 弱动词名词化改强动词（头号习惯）
- **实证**：进行 3887 次/41 篇、实现 701、开展 521、加以 67、予以 18——"进行/实现/开展/加以/予以 + X"是高频构造。
- **规则**：实现/开展/加以/予以 + X 属弱动词，优先改为裸动词或更具体动词（开展实验→实验；实现目标→达成目标）。**"进行"经用户明确"可以使用"，且本语料极高频（3887/41篇）多为范式用法，可用、不强制改**；仅当明显冗余（"进行调研"→"调研"）时精简。check.py 不再机械标记 进行。
- **正**：「**开展实验**」→「**实验**」；「**实现目标**」→「**达成目标**」；「**进行调研**」→「**调研**」（仅冗余时改，非强制）。
- **反**：把"进行研究"改成更有 Nature 味的花式名词（仍属弱表达）。

### R4 多层"的"拆包
- **实证**：句中 ≥3 个"的"嵌套 1605 次、覆盖 34/41 篇。
- **规则**：拆开嵌套定语——断句、换"其中/该/其"、或用介词结构（"关于…的"→"就…"）。
- **正**：「在某种具体行为中由外因或内因影响而产生的不利于…思考的情感」→「在具体行为中由内外因引发、妨碍正常工作思考的情感」。
- **反**：保留五六个"的"连珠，读者回读三遍才懂。

### R5 模糊量词具体化
- **实证**：一些/较多/一定程度/部分/若干 等 1620 次、覆盖 33/41 篇。
- **规则**：能查到数就换具体数字/比例/范围（"部分公园"→"12 座样本公园中的 9 座"）；查不到则标明"据调查/样本显示"并限定范围，不假装精确。
- **正**：「**部分**公园悬挂植物名牌」→「样本公园中 **9 座**悬挂植物名牌」。
- **反**：硬编一个精确数字（"37.5% 的公园"）掩饰"部分"。

### R6 迂回表达简化
- **实证**：通过…的方式/手段 165 次、起到…作用 128 次。
- **规则**："通过 X 的方式/手段"→直接动词；"起到…作用"→具体动词（发挥/提供/促进/支撑）。
- **正**：「景观绩效评价是通过一个客观、严谨的**方式来评价**公园建设成果」→「景观绩效评价客观、严谨地**评价**公园建设成效」。
- **正**：「悬挂植物名牌，**起到了**植物科普**作用**」→「悬挂植物名牌，**科普**植物知识」。
- **反**：把"起到作用"改成更绕的"发挥了一定的功能性效用"。

### R7 被动节制（非全面改主动）
- **实证**：被…所 29、由…进行/完成 34、为…所 159，合计 ≈220 次、仅 25/41 篇。被动在本语料远非"普遍问题"。
- **规则**：方法/结果陈述中的被动（"数据被收集""样本被分为"）**可接受**，保留学科惯例；仅改生硬迂回被动"被…所/由…完成"，其余不动。不要像 Nature 那样全面翻主动。**注**："进行"经用户明确"可以使用"，"由…进行"不再作为生硬被动处理。
- **正**：「数据**由**问卷调查**收集**」（保留）／「该结论**被**既有研究**所证实**」→「既有研究证实了该结论」。
- **反**：把"采用 AHP 法计算权重"硬改成主动而丢失方法客观性。

### R8 学科必要范式保留
- **实证**：随着… 472/32、采用/运用/基于…方法 590/34、结果表明/研究显示 294/27、"本文以…为研究对象"近乎普遍。
- **规则**：以下框架是风景园林学位论文的**必要范式**，润色时保留，不可为追简洁删去：
  - 绪论：「本文以 **X** 为研究对象，以 **Y** 理论为指导，运用 **Z** 方法，旨在…」
  - 背景：「随着…（城市化/老龄化/生态文明），X 问题日益凸显」
  - 方法：「采用 **AHP / 空间句法 / SD 法 / GIS 叠加**，从…维度构建评价指标体系」
  - 结果：「结果表明 / 研究发现 …」
  - 结论：「为 … 提供理论依据与实践参考」
- **反**：把这些当成 Nature 式"套话"一刀切删掉，论文反而不像学位论文。

### R9 空泛套话克制（可轻强调，不堆叠不空泛）
- **实证**：具有重要的…意义 84/25、不可或缺/至关重要 75/22、日益/越来越 167/27。
- **规则**：可作轻强调保留，但（1）不堆叠（一句别同时"重要+不可或缺+日益"）；（2）"具有重要意义"必须指明**何种**意义（理论/现实/方法），不能空收尾。
- **正**：「对城市健康治理**具有现实意义**」（指明现实）／「对…**具有理论意义与现实意义**」。
- **反**：「该研究具有重要的意义」（无所指，空泛）。

### R10 术语与缩写保全
- **实证**：本批高频术语见 `domain_lexicon.md`（景观连通性、生态系统服务(ES)、恢复性、空间句法、绿视率、AHP、SD 法等）。
- **规则**：术语与缩写原样保留，不口语化改写、不擅自简写或扩写。首次出现用"中文全称（缩写）"。
- **正**：「生态系统服务（ES）」「景观连通性」。
- **反**：把"生态系统服务"随手改成"生态服务"、"恢复性环境"改成"治愈环境"。

### R11 不编造、只改表达
- 数字、结论、引用、专业判断一律不动；拿不准的宁可保留原表述并标注，绝不硬编。
- 无法核实的"精确化"不要编，保留原模糊表述并注明待补。

### R12 庄重守规范
- 保留学位论文必要句式与庄重语体，不口语化、不中英杂糅生硬、不模仿自媒体腔。
- 英文摘要套用国际学术英文通则（短句、主动、无 fluff），但中文正文不受此限。

## 三、与 Nature 假设的关键分歧（为什么不能直接用 nature-polishing）

| 旧 nature-polishing 假设 | 本语料实测 | 修正 |
|---|---|---|
| 句子要短（>45字优先拆） | 中位 60 字、22%>100 字，长句是常态 | R1：不普遍拆短，仅 >150 字多分句才拆 |
| 删显式衔接词追求自然 | 因此/然而/综上所述 1379 次/36 篇，是论证纹理 | R2：保留衔接词 |
| 被动一律改主动 | 被动仅 ≈220 次/25 篇，远非普遍 | R7：被动可接受，仅改生硬"被…所/由…进行" |
| 去"随着…"等背景套话 | 随着…472 次/32 篇，是必要范式 | R8：保留背景框架，勿堆叠 |
| 强动词（删进行/加以） | 进行 3887 次/41 篇才是头号习惯 | R3：实测头号弱点是弱动词名词化，重点改 |

> 真正应从本语料改掉的本地弱点（按频次排序）：**弱动词名词化（进行/实现/开展/加以/予以）＞ 模糊量词 ＞ 多层"的" ＞ 迂回表达（通过…的方式/起到…作用）**；而"短句、去衔接、全面改主动"是 Nature 的偏好，**不是这批论文的问题**。

## 四、风格与反 AI 腔规范（用户要求，R13–R34）

> 本节约去前两节的"语料实测"口径，转为**用户对成文风格的硬性禁忌**——目标是让文字不像 AI 生成、不像营销号、不像故弄玄虚。符号类（R13/R14/R15/R17）语料实测仍高频（破折号 513、冒号 5982、引号 12226、括号 13836 次/41 篇），故定位"克制、非必要不出现"；其余为纯风格禁忌，硬性避免。
> `check.py` 机械标记：R13（破折号）、R16（空泛修饰）、R18（非常见符号）、R20（"这不是…而是…"）、R29（孪生词）；其余为软约束，靠判断。

### 一、标志性标点符号滥用

- **R13 少用破折号"——"**（513/41）：非必要不用引导解释/强调；尤忌"重点不在于…——而是…"式强行转折。改逗号、分号或另起分句。
  - 正：「单元层遵循"规划是活的而非死的"逻辑——建立评估机制」→「单元层遵循该逻辑，建立评估机制」。
- **R14 少用冒号"："**（5982/41）：忌"先概括词/短句 + 冒号引内容"的模板化，如"原因有三点：A是…：…；B是…：…"。短句用"即/为/包括"或逗号；仅长列举保留冒号。
  - 正：「主要职责应包括：审议…、协调…」→「主要职责包括审议…与协调…」。
- **R15 少用引号""""**（12226/41）：仅用于①直接引语；②真正 coined/外来术语首发；③反讽/特殊含义。忌给普通概念或自造词组加引号（如"个体认知""系统性升维"），显得强行定义、故弄玄虚；论述中普通词去引号正常行文。
  - 正：「需要的是"保护"而非"修复"」→「需要保护而非修复」。
- **R17 少用括号"（）"**（13836/41）：能并入正文就并入；仅留术语全称（缩写）与文献标注。
  - 正：「研究区（位于东部）」→「研究区位于东部」。
- **R18 慎用非常见符号**：人文社科论文非公式语境禁用 ≠、≈、→、⇒ 等替代自然语言（如"保护≠修复"应写"保护不同于修复"）。公式、流程箭头除外。
- **R19 顿号无效堆砌**：忌罗列同类型非核心词形成"头衔式"臃肿，如"某某学者、研究员、教授……"；同类精简或归入概括词（"相关领域专家"）。

### 二、典型高危句式与语法结构

- **R20 忌"这不是…而是…"二元对立**：AI 惯用强行转折套路（如"这不是简单的'输血'，而是一场深度的系统重组"）。改用平实对比或递进。
- **R21 主语补全**：忌句首直接以状语/动词起句导致主语缺失（如"借助完善的制度保障，将人力资源优势转化为…"缺"谁"）。明确执行者（本研究 / 作者 / 某主体）。
- **R22 控制超长复合句**：忌一段内连续多从句、插入语长难句、缺乏断句与节奏（阅读极差）。按 R1 节奏，必要时在分句处断句、长短交替。
- **R23 忌动词直接起句堆砌**：少以"构建了 / 提出了 / 分析了 / 建立了 / 设计了"等过去式动词直接起句（机械生硬）；可加"本文 / 本研究"或融入论述。方法陈述（"采用…""结果表明"）属范式不在此限（见 R8）。
- **R24 控制"了"字反复**：描述动作/状态变化忌"融入了 / 结合了 / 实现了"等"了"字动宾堆砌（重复感、口语化）；省"了"或换表述。

### 三、词汇选择上的"AI 病"

- **R16 空泛修饰**（系统性 157/41）：删无论证的"系统性 / 综合性 / 整体性 / 根本性 / 实质性 / 全方位"等（也涵盖用户所举"系统性升维"类自造组合）。
- **R25 拒绝对造学术黑话**：勿突兀用"吊诡 / 祛魅 / 嬗变 / 构境"等晦涩词；确需用须有上下文铺垫。
- **R26 拒绝流行/互联网黑话**：勿堆"赋能 / 闭环 / 底层逻辑 / 颗粒度 / 对齐"等；学术语境用规范术语。
- **R27 拒绝对大空洞宏大词**：避免"系统性扭曲 / 四重绞杀 / 历史性胜利 / 全局升华"等程度过重、口气过大词，尤忌理论意义部分浮夸；用克制具体表述。
- **R28 拒绝营销式强调语气**：勿用"手把手教你 / 必须告诉你的是 / 核心密码 / 讲透本质"等；保持严谨客观。
- **R29 拆"和/或/与"孪生词**：避免两近义词用和/或/与连接成冗余（"研究与分析 / 合作与交流 / 真实性与艺术性"）；择一或并得更准词。
- **R30 删无意义华丽修饰**：名词前勿叠加大量形容词追华丽（"进行具体准确的归纳与详尽客观的总结"→"归纳总结"；"增强竞争力"勿扩成冗长空洞描述）。

### 四、逻辑结构与行文风格

- **R31 避免极致"总分总"机械结构**：每段/每论点不必严格"提观点—展开—总结"；允许自然起伏、灵活过渡。
- **R32 避免冒号式小标题**：目录/各级标题少用"XXX：…"格式，求变化（见 R14）。
- **R33 避免观点与例子机械捆绑**：每观点后紧跟一例的模式化；可交错、分组举例。
- **R34 尽量少用分号"；"**：全文非必要不出现分号；段内并列要点勿用分号罗列，用连贯叙述或逗号、句号串联（见 R13/R14 符号克制）。

## 五、从原始实验结果 / 笔记 / 数据描述生成论文段落的规范（R35–R45）

> 本节针对 `landscape-thesis-writing` 的**新输入模态**：用户不直接给"研究要素"，而是给**原始材料**——①实验结果（统计量、p 值、显著性、图表结论）；②田野/观测笔记（bullet 观察、未结构文字）；③数据描述（原始测量值、字段说明、表格）。目标是把这些**杂乱原始材料**转写为符合风景园林学位论文规范的"结果与分析"段落。
> 锚点仍为 42 篇语料实测：结果章节共 **105 个"结果与分析"章**，真实表述见下。标注【语料】者来自实测统计；未标注者为学科通用学术规范，但与本语料实测不冲突，承接 R1–R34。

### 一、输入判别与归一化

- **R35 先判输入类型，再选生成策略【语料】**：原始材料分三类，处理路径不同——①**实验结果**：统计量（均值±SD、p、效应量、显著性标记 *）、图表结论；②**田野/观测笔记**：bullet 观察、现场记录、未结构文字；③**数据描述**：原始测量值、字段说明、表格。混合型（如"实验数据 + 笔记"）先分段再各自成段。
  - 正：「输入含 ANOVA 结果表 + 一段现场观察」→ 拆为"结果"段（表）与"现象描述"段（笔记）。
  - 反：把笔记当统计结果、凭观察下显著性结论。

- **R36 不编造统计量（承接 R11）**：原始材料**未给**的推断统计量（p 值、置信区间、相关系数、效应量）绝不补；若只有描述性笔记，只生成"描述性结果"段落，并明确"本研究未做推断统计"，不假装显著性。
  - 正：「笔记：A 地块植被覆盖低、人流量大」→「A 地块植被覆盖较低且人流量偏大」（描述性，无显著性声称）。
  - 反：「A 地块植被显著低于 B 地块」（原文无检验，硬加"显著"）。

### 二、数字、单位与图表

- **R37 数字精度与单位守恒（承接 R5/R10）**：保留原始小数位与单位；绿视率(GVI)/天空可视因子(SVF)/NDVI/景观连通性/LST/HRV 等指标保留单位与精度，不增减有效数字；百分比、均值±标准差按原格式誊写。
  - 正：「GVI 均值 0.23±0.04」「NDVI 由 0.41 升至 0.58」。
  - 反：把"23.750*"四舍五入成"24"、擅自删单位。

- **R38 图表对应、提炼非罗列【语料】**：结果章节高频"由上表 X 可知""如图 X 所示"（见 105 章实测）。保留图表引用；文字只述**关键趋势、排序与差异**，不把表格数字全抄进正文（与图表重复）。
  - 正：「由上表 13 可知，四组在远离性上存在显著差异，其中水体组得分最低」。
  - 反：把整张表 12 行数字逐条誊进正文。

- **R39 显著性表述规范【语料】**：语料用"X 与 Y 存在显著差异""X 显著高于 Y"，星号含义为"* p<0.05、** p<0.01"（见 templates openers"注：* p<"）。用规范表述；禁用"非常显著""极显著"等不规范词（承接 R9 克制）；p 值保留原小数位。
  - 正：「城市组与基线水平存在显著差异（p<0.05）」「林下组唤醒度降低最少（−0.25）」。
  - 反：「城市组极其显著地高于基线」「p 值大概 0.1 几」。

### 三、时态、语态与因果

- **R40 结果句客观态、与方法句区分（承接 R7/R23）**：结果陈述用"实验测得/数据显示/分析表明"等客观引入，可被动（"数据经方差分析显示…"）；避免段段以"本研究发现/结果表明"起句（承接 R23 动词起句忌）；"采用…方法"属方法句不混入结果段。
  - 正：「方差分析显示，四组在延展性上差异显著」「数据显示，水体对消极情绪恢复效果最好」。
  - 反：每段开头"本研究发现…本研究发现…"（机械堆砌）。

- **R41 相关≠因果（承接 R20/R27）**：数据只支持相关/差异时，用"X 与 Y 呈正相关/存在关联/具有显著差异"，不用"X 导致 Y/造成 Y"；因果推断须有实验或模型支撑，不夸大（承接 R27 不宏大空洞）。
  - 正：「绿视率与情绪恢复呈正相关」「斑块面积与连通度显著相关」。
  - 反：「高绿视率导致情绪恢复」（观察性数据越界断言因果）。

### 四、笔记 / 数据 → 段落

- **R42 描述性笔记升段（notes→prose，承接 R2/R11）**：bullet 观察扩为连贯段落，按"空间特征→表现→可能机制/影响"递进；用显式衔接（因此/在此基础上/与此同时，承接 R2）串成线性推进；不丢原始事实、不添加未观测结论。
  - 正：笔记「A 地块植被少；B 地块人多；C 地块座椅破损」→「A 地块植被覆盖较低，B 地块使用人群偏多，C 地块座椅出现破损——三处均指向更新优先级较高」（只整合事实，机制用"指向"不越界）。
  - 反：把笔记改写时新增"因此居民幸福感下降"（原文无此观测）。

- **R43 数据描述转叙述（data→prose，承接 R33/R34）**：原始字段/测量值先归为"分布/量级/对比/趋势"四类叙述单元再成文；同类指标合并比较，避免逐条罗列（承接 R33 观点例子不机械捆绑、R34 少分号）。
  - 正：「各样方 NDVI 介于 0.31–0.67，均值 0.49；建成区样方普遍低于绿地样方」。
  - 反：逐条「样方1=0.31；样方2=0.45；样方3=0.52…」（罗列无叙述）。

### 五、领域保全与边界

- **R44 指标术语保全（承接 R10）**：绿视率(GVI)/天空可视因子(SVF)/NDVI/景观连通性/空间句法/恢复性/各问卷维度等专业术语与缩写原样保留，首次出现"中文全称（缩写）"。
  - 正：「绿视率（GVI）」「心率变异性（HRV）」。
  - 反：把"绿视率"随手改成"绿色可见度"、"NDVI"扩成"归一化植被指数"丢掉缩写。

- **R45 结果与讨论分离，但结果后须补"现实解释"（基于 gen_guide 分章节取向，呼应 R46）**：生成"结果与分析"分析段时，在摆出事实与差异之后，紧跟一句**由本数据直接支撑的"现实解释"**——用平实语言说明该结果在真实滨江游憩场景中的含义（如"绿视率更丰富的样段更契合使用者游憩期待"）。机制阐释、与文献对标、设计处方仍留到"讨论"，不在结果段越界做未测因果论断或抛新结论（承接 R9/R27 不夸大）。
  - 正：结果段「GVI 与游憩满意度显著正相关（r=0.869，p<0.05）。这表明绿视率更丰富的滨江样段更契合使用者的游憩期待，空间绿量本身即构成体验优势。」；讨论段再写「这与恢复性环境理论一致，提示更新中应优先保护高绿视率界面」。
  - 反：结果段直接写「因此滨水设计应全面推广」（越界到讨论/结论处方），或只给数字不给现实含义（见 R46）。

- **R46 数据分析结果描述后必须补"现实解释"（R45 的落地要求）**：每一处关键数据结论（数值趋势 / 相关 / 组间差异）之后，补一句**把数字翻译成真实场景含义**的解释，避免"只堆数据、不落地"。现实解释须满足：①由本数据直接支撑，不引申未测机制；②不在此给设计处方（处方留"讨论"）；③用平实语言，不夸大（承接 R9/R27）。深度阐释（理论对标、设计启示）仍留"讨论"。
  - 正：「硬质铺装率与游憩满意度显著负相关（r=−0.858，p<0.05）。这说明硬质化过度的滨江段削弱了使用者的游憩舒适感，铺装宜控量提质。」
  - 反：「硬质铺装率与游憩满意度 r=−0.858。」（只给数字、无现实含义，读者不知其意）。
