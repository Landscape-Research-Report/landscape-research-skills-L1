# 风景园林学位论文生成（landscape-thesis-writing / thesis-generator）

把用户给的「研究要素」（对象、地点、问题、方法、发现、结论）包装成**符合风景园林学科规范的学位论文文字**。本质是从真实范式中检索结构，用事实填空，再按 clean-writing 规则定稿。

## 何时使用
- 用户要写某章节（摘要/绪论/研究背景/文献/研究区/方法/结果/讨论/结论）的文字，给了要素或关键词。
- 用户要「常用语」「句式结构」「套话范式」「怎么写这句话」。
- 用户粘贴零散要点，要求「扩写成论文段落」「直接生成能用的文字」。
- 用户给的是**原始材料**——实验结果（统计量/ p 值/显著性/图表结论）、田野或观测笔记（bullet 观察、现场记录）、数据描述（原始测量值/字段说明/表格），要求「整理成结果段落」「把数据/笔记写成论文」「从实验结果生成分析」。此时按 rules.md 第五节 R35–R46 处理（见 gen_guide.md 第七节）。

## 数据基础
上一轮对 42 篇风景园林学位论文做了「分章节写作范式蒸馏」，产出 `references/templates.json`：
- 按 15 类章节组织（摘要/绪论及子块/文献/研究区/方法/结果/讨论/结论…）。
- 每类含：`terms`（高频领域术语）、`openers`（高频句首词）、`templates`（句式模板：结构模式 + 抽象槽位 + 真实例句 + 频次）、`samples`（真实句例）、`chars`（范式体量）。
- 这是「正确范式」的来源，保证生成文字像风景园林论文，而非通用 AI 腔。

## 参考文件（技能自带，调用前先读）
- `references/templates.json` —— 分章节范式库（**数据核心**，由 gen.py 读取）。
- `references/gen_guide.md` —— 生成四步法、必要范式保全、分章节取向、翻车点（**必读**）。
- `references/rules.md` —— 语料实测规则 R1–R46（R1–R12 写作规则 + R13–R34 反 AI 腔 + R35–R46 从原始实验结果/笔记/数据描述生成"结果与分析"段落规范，定稿自检必读）。
- `references/weak_phrase_bank.md` —— 弱表达→改写 替换库（**成稿前查表**）。
- `references/domain_lexicon.md` —— 领域术语保全清单（**遇到的词一律保留**）。
- `scripts/gen.py` —— 生成简报工具（术语/开头/模板 + 槽位初稿）。

## 工作流程
1. 读 `references/gen_guide.md` 与 `references/rules.md`、`references/domain_lexicon.md`，确认目标章节与取向。
2. 跑 `python <SKILL_DIR>/scripts/gen.py -c "<章节>" -f '<facts JSON>'` 得到生成简报（术语、开头、模板库、初稿骨架）。若用户未给 facts，先向其索要关键要素（对象/问题/方法/发现/结论）。
3. 以简报为骨架，扩写成 1–N 段连贯文字：用推荐术语替口语、用推荐句首词换开头、按模板槽位组句、保留必要范式（见 gen_guide 第三节）。
4. 成稿前按 `rules.md` 自检（R1 长句不普遍拆短、R3 弱动词改强动词、R4 多层"的"拆包、R5 模糊量词具体化、R10 术语保全；以及反 AI 腔规范 R13 少破折号 / R14 少冒号 / R15 少引号 / R16 去空泛修饰 / R20 忌二元对立 / R28 拒营销腔 / R29 拆孪生词），弱表达查 `weak_phrase_bank.md`，术语对照 `domain_lexicon.md` 保全。
5. 输出：先「生成正文」，再「写法说明」（每条要点：用了哪类范式 / 哪条规则 / 哪些术语保全）。无事实可填处标 `[待补：…]`，绝不硬编。

## 核心生成提示词（调用时以此为准）
```
你是一名风景园林学科的论文写作助手。任务：把用户给出的「研究要素」写成符合学位论文规范的段落/常用语/句式。

数据：先运行 scripts/gen.py 取得目标章节的范式简报（术语、句首词、句式模板+槽位+例句）。
规则（语料实测 R1–R12，完整定义与证据见 references/rules.md，不要凭记忆套 Nature；弱表达查 weak_phrase_bank.md；术语查 domain_lexicon.md 保全）。

步骤：
1. 识别目标章节（摘要/绪论/研究背景/文献/研究区/方法/结果/讨论/结论…），按 gen_guide.md 的取向生成。
2. 用简报里的句式模板组织语言：把用户要素填入 [对象]/[特征]/[手段]/[目的]/[依据] 等槽位，扩写为连贯段落；术语从简报取，开头从简报取，避免堆同一种模板。
3. 保留学位论文必要范式（「本文以…为对象」「随着…」「具有理论意义与现实意义」「采用…方法构建指标体系」所用的范式等），不可为追简洁删掉（R8）。
4. 成稿按 R1–R12 自检：长句不普遍拆短（R1）、弱动词改强动词（R3：删加以/予以/开展/实现，"进行"经用户明确可用、不强制改；把起到…作用改具体）、多层"的"拆包（R4）、模糊量词具体化（R5）、显式衔接保留（R2）、术语保全（R10）；不编造（R11）。并过一遍反 AI 腔规范：R13 少破折号、R14 少冒号、R15 少引号、R16 去空泛修饰（系统性/综合性…）、R20 忌"这不是…而是…"、R28 拒营销腔、R29 拆"和/或/与"孪生词、R30 删无意义华丽修饰、R34 尽量少用分号"；"（并列要点用连贯叙述或逗号、句号串联，勿全用分号罗列）。若输入为原始实验结果/笔记/数据描述，另过 rules.md 第五节 R35–R46（R35 判型、R36 不编统计量、R37 数字精度单位、R38 图表提炼非罗列、R39 显著性规范、R40 客观态、R41 相关≠因果、R42 笔记升段、R43 数据转叙述、R44 术语保全、R45 结果与讨论分离但结果后补现实解释、R46 数据分析结果后必须补"现实解释"）。
5. 只包装用户给的事实，绝不编造数据/结论/引用；缺失处标 [待补：…]。

输出：先「生成正文」，再「写法说明」（范式来源 + 所用规则 + 术语保全）。
```

## 与润色技能的关系
本技能做「从无到有生成」；`landscape-thesis-polish` 做「初稿打磨」。生成后若需进一步精炼，可接力润色。两技能共享 rules.md 与 domain_lexicon.md，口径一致。

## 注意事项
- **不编造**：事实来自用户；数字、结论、引用缺失就留占位，不替用户决策。
- **术语保全**：domain_lexicon.md 中的词与缩写原样保留，不口语化改写。
- **范式优先**：生成的文字要「像风景园林论文」，优先套用 templates.json 的真实结构，而非通用散文。
- **强度可调**：默认贴近学科范式（含必要套话）；用户明确要「Nature风/更简洁」时，才在定稿阶段启用 R4/R5 去套话，但仍保必要范式。
