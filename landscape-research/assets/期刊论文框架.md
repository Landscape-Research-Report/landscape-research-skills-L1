# 期刊论文框架模板（可直接套用）

> 来源：研究生指南《论文写作_期刊论文》Q74「研究框架」+ Q75「写作顺序」。风景园林定量类期刊论文普遍采用下面这套"八股文"骨架，先有图表逻辑再反推文字框架。

## 一、标准章节骨架（多级标题）

```
0  前言（Introduction）
1  研究区与数据来源
    1.1  研究区概况
    1.2  数据来源与预处理
2  研究方法
    2.1  方法1（如 InVEST / 景观指数 / 问卷信效度）
    2.2  方法2
    2.3  方法3
3  结果与分析
    3.1  结果1
    3.2  结果2
    3.3  结果3
4  结论与讨论
    4.1  结论
    4.2  讨论
参考文献
```

## 二、写作顺序（推荐，避免卡壳）

1. **先定图表**：列出文章会出哪些图/表，排好它们在文中的逻辑顺序——图表逻辑≈全文框架逻辑。
2. **定各级标题**：按图表梳理标题。
3. **先写结果+讨论**：最熟悉、篇幅最大、最难，可参考相近已发表论文的"结果-讨论"固定结构。
4. **再写前言**：讲好"领域背景→现存问题→研究内容"的故事线，最难也最关键。
5. **写研究区+数据+方法**：相对简单，但方法部分是体现科学性的重点，务必参考相近文献。
6. **最后写摘要**：摘要=正文缩写版，前面不定稿就无从下手。
7. 始终**模仿已发表同类型论文的写法**，不要凭空发挥。

## 三、各章节写法要点速记

- **题目**：20 字内，言简意赅。范式：「基于XX方法的XX对象XX内容研究」「XX视野下XX表征」「XX对XX的影响机制」。
- **摘要**：背景→方法→结果（分条）→结论→展望，中文≤400 字、英文≈150 词。
- **前言**：领域背景→研究内容背景（前人工作+不足，用"然而"引出缺口）→本研究方法优势→研究内容与拟解决关键问题。
- **方法**：含义+指标+公式+各指标内涵+结果含义；强风景园林论文需补充"为什么这样研究"的思路说明。
- **结果**：先展示数据再解读；重要结果必配图/表，图不重复表；结果与讨论（国内常混写）要区分——结果是确定性内容，讨论是可能性推断。
- **结论**：总分模式，帽段改写摘要/前言；每条重要研究内容单列一条，凝练普适性观点。
- **讨论**：由小见大，不与结果重复；纵向分析"为什么出现该结果"，横向与前人结果比对验证。
- **图片**：框架图可用 PS/PPT；统计图用 R(ggplot2)/Origin；地图用 ArcGIS 直出（须含指北针/图例/比例尺，全国图不得缺台湾、南海诸岛，中文核心常需审图号）；配色尽量与研究语义相符。
