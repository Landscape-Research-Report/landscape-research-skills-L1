# 分章节润色取向（chapter_guidance.md）

> 不同章节的“润色强度”与“该保什么”不同。本文件与上一轮「分章节写作范式蒸馏」的章节类型对应，供 agent 在润色时按章节切换取向。默认取向见每节末尾标注（保范式 / 去空泛 / 精确 / 谨慎）。

## 摘要（中文）
- 信息密度最高：一句话说清“对象—方法—核心发现—意义”，删背景铺垫。
- 常见弱表达：“近年来…”“在…背景下”“一定的/较大的”。
- 取向：**去空泛 + 精确**。结论先行，关键数字保留。

## 摘要（英文）
- 套 Nature 英文规则：短句、主动、无 fluff、压低缩写；说清 found / did / why，不过度宣称（no over-hype）。
- 取向：**Nature 英文风**。

## 绪论（含研究背景 / 研究意义 / 国内外研究现状 / 研究内容）
- “本文以…为研究对象”“在…背景下”是**必要范式**，轻度取向保留；深度取向只删真正空泛的引导，不删研究定位。
- 国内外研究现状最易堆“近年来…不断涌现”，改为具体进展+缺口。
- 取向：**保范式 + 去空泛**（轻度保框架，深度收套话）。

## 文献综述与理论基础
- 术语密集，严格对照 `domain_lexicon.md` 保全；缩写首次给全称。
- 避免“综上所述”前缺衔接（R9）。
- 取向：**术语保全 + 显式衔接**。

## 研究区概况与数据来源
- 地理/历史陈述用短句、主动（R2）；“由…组成”“位于…”等描述性句保留。
- “一定的/相关的”量化（R10）。
- 取向：**精确 + 主动**。

## 研究方法
- 方法名+工具名保全（GIS、SBE、IPA、AHP、CiteSpace、ENVI-met…）；“采用…方法”可保留（非弱动词）。
- 删“通过…的方式”（R 中的弱表达）。
- 取向：**术语保全 + 去弱表达**。

## 结果与分析
- 数据驱动：用“表明/显示/发现”而非“可以看出/值得一提的是”（R4）；模糊量词换具体（R10）。
- 每句一意，长结果句拆分（R1）。
- 取向：**精确 + 短句**（最该用深度取向）。

## 讨论
- 因果措辞谨慎：关联≠因果，用“可能/或/与…一致”，避免“证明了”（R12 底线）。
- 显式衔接（R9）。
- 取向：**谨慎 + 显式衔接**。

## 结论与展望
- 凝练可落地：用“为…提供依据/支撑”“旨在…”等（见蒸馏结论范式），删空泛展望。
- 取向：**凝练 + 保范式**。
